# Hnýfill

Website preview: https://einarsigurdur.github.io/hnyfill/

## Development

`pnpm install --frozen-lockfile` then `pnpm dev`.

## GitHub Pages

Run `pnpm build:pages`, commit the source changes and generated `docs/`, and push to `main`.
GitHub Pages serves `main` → `/docs`. The build uses `/hnyfill` as its base path.
The default `pnpm build` continues to support root-domain hosting.

The preview remains marked noindex. Product details and photography are preserved from the verified Hnýfill draft. No license to reuse brand assets is granted.
